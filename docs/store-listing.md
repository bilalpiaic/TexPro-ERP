## Full description

TexPro ERP is an Android accounting system for textile converters and weaving/processing mills.

Track a lot from customer sale order through grey cloth purchase, dyeing and printing, CMT stitching, and finished-goods invoicing. Each step posts categorized vouchers (JV, CR, CP, BP, BR, Sale, Purchase) to a double-entry general ledger.

On this device you can:

- Book sale orders with quality, blend, width, pieces, and meters
- Run lot-wise production with grey, WIP, finished fabric, and packed units
- Post journal, cash, bank, sale, and purchase vouchers
- Review trial balance, profit and loss, balance sheet, and inventory value
- Create mill organizations and optionally sign in with Google to sync a tenant to the cloud

Sample mill data is included so you can learn the workflow before entering live books. Cloud sync is optional. Financial data stays on the device unless you sign in and tap Sync Cloud.

TexPro ERP is built for mill owners, accountants, and production managers. It is not a consumer shopping app.
